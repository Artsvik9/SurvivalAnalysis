# Survival Analysis Homework – Customer Churn and CLV

This repository contains Survival Analysis of telco.csv file

## 📌 Overview

The goal of the project is to:
- Analyze customer churn using survival models
- Build AFT models with all available distributions
- Compare models based on AIC and Concordance Index
- Calculate Customer Lifetime Value (CLV) using the final model
- Visualize survival curves and CLV distributions
- Explore retention strategies and at-risk customer segments

## 📂 Contents

- `Survival_Analysis.ipynb`: Main notebook with code, visualizations, and report
- `Survival_Analysis.py`: Source code (core logic without markdown)
- `requirements.txt`: Python package dependencies to reproduce results
- `README.md`: This file — a short summary of the assignment
